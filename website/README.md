# Baku 2025 · F1 Telemetry Analytics website

F1-styled static website (React + Vite) that visualises the outputs of the Spark/YARN pipeline in `../code`.

## Pages

| Route | What it shows |
|---|---|
| `#/` | Event overview, podium, sessions, teams |
| `#/replay` | Live replay of any session: every car on the Baku map (0.5 s resolution), live timing tower with interval/gap from 20 timing loops per lap, tyres, pit status, track status (Yellow / SC / Red), race control messages, team radio and a live gap chart |
| `#/race` | Classification, **the worm** (gap to leader per lap) with Safety Car bands, race trace, position chart, tyre strategy |
| `#/telemetry` | Fastest-lap comparison for up to 3 drivers: speed, delta, throttle, brake, gear, synchronised with a track-dominance / speed map |
| `#/laptimes` | Lap-time scatter (by tyre or driver), pace distribution, best sectors and ideal lap |
| `#/insights` | Spark MLlib results: tyre degradation, K-Means driver clusters, chase graph, anomalies, next-lap model evaluation |
| `#/predictor` | User inputs → Spark Random Forest (80 exported trees run in the browser), stint projection per compound, tree-vote spread |
| `#/pipeline` | Cluster, HDFS/YARN set-up and the Spark jobs |

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/ (works from any folder / GitHub Pages)
npm run preview    # serve dist/ on http://localhost:4173
npm run check      # verify every route, data file, image and audio link
```

## Rebuilding the data

`public/data`, `public/img` and `public/audio` are generated by `scripts/build_data.py` from:

- `project_bda/f1-azerbaijan/data/*.csv` – raw TracingInsights CSVs (same files as HDFS `/bda/f1-telemetry/raw`)
- `f1_dashboard_data/analysis_v2/` – Spark outputs pulled from HDFS
- `f1_dashboard_data/model_export/next_lap_rf.json` – from `code/f1_export_rf_model.py` (run on YARN)
- `data_sources/tracinginsights_2025/` – circuit corners, drivers/team colours, race control, team radio, images

```bash
npm run data       # python scripts/build_data.py (needs pandas, pyarrow, pillow)
```

The replay positions are a visualisation-only resampling of the raw telemetry; all analytical tables
(fastest laps, stints, positions, ML results) come from the Spark jobs.
